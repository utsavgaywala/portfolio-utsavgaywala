# Utsav Gaywala - Portfolio Website

A modern, elegant, and fully responsive personal portfolio website showcasing expertise as a Senior Full-Stack Developer.

## 🌟 Features

- **Modern Design**: Premium aesthetics with gradient accents, smooth animations, and hover effects
- **Fully Responsive**: Mobile-first design that adapts perfectly to all screen sizes
- **Smooth Animations**: Fade-in effects, scroll animations, and interactive elements
- **SEO Optimized**: Proper meta tags, semantic HTML, and structured content
- **Accessibility**: Focus states, ARIA labels, and keyboard navigation support
- **Performance**: Optimized loading, lazy animations, and efficient code

## 📋 Sections

1. **Hero Section** - Introduction with call-to-action buttons and social links
2. **About Section** - Professional summary with key statistics
3. **Skills Section** - Technical expertise organized by categories
4. **Projects Section** - Featured projects with detailed descriptions
5. **Education Section** - Academic background and coursework
6. **Contact Section** - Multiple contact methods
7. **Footer** - Quick links and social connections

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **Tailwind CSS** - Modern utility-first CSS framework (via CDN)
- **Custom CSS** - Additional animations and styling
- **Vanilla JavaScript** - Interactive features and smooth scrolling
- **Google Fonts** - Inter font family for modern typography

## 🚀 How to View

### Method 1: Direct File Opening
1. Navigate to the project folder: `d:\My Portfolio\UtsavGaywalaPortfolio`
2. Double-click on `index.html` to open it in your default browser

### Method 2: Using VS Code Live Server
1. Open the project folder in Visual Studio Code
2. Right-click on `index.html`
3. Select "Open with Live Server"

### Method 3: Using Python HTTP Server
```bash
cd "d:\My Portfolio\UtsavGaywalaPortfolio"
python -m http.server 8000
```
Then open `http://localhost:8000` in your browser

### Method 4: Using Node.js http-server
```bash
cd "d:\My Portfolio\UtsavGaywalaPortfolio"
npx http-server -p 8000
```
Then open `http://localhost:8000` in your browser

## 🔧 Customization

To customize the portfolio:

1. **Personal Information**: Edit the contact details in `index.html`
2. **Colors**: Modify the Tailwind config in the `<script>` tag or `styles.css`
3. **Content**: Update sections in `index.html`
4. **Animations**: Adjust timing and effects in `styles.css` and `script.js`

## 📊 Performance

- **No external dependencies** (except Tailwind CSS CDN and Google Fonts)
- **Optimized animations** using CSS transforms and transitions
- **Debounced scroll events** for better performance
- **Lazy loading** for animations
- **Custom scrollbar** styling for better UX
